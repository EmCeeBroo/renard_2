## 📂 Project History

This repository contains a refined and documented version of **Renard**, a restaurant reservation system originally developed as a graduation project by a five-member team using Scrum methodology.

The goal of this version is to provide a clearer view of the project's architecture, implementation, and technical documentation while preserving the core functionality and design decisions of the original system.

For those interested in exploring the original development process, team collaboration history, and complete commit timeline, the historical repository is available below.

## 🚀 What I Learned

Renard was my first large-scale full-stack project and became the foundation of my software development journey.

Throughout its development, I gained practical experience in:

* REST API design and implementation
* Relational database modeling
* JWT authentication and role-based access control
* Team collaboration using Scrum methodology
* Git workflows and version control
* Frontend and backend integration
* Layered architecture and software design principles
* Project documentation and maintenance
* Requirement analysis and system planning
* Debugging, refactoring, and code organization

More importantly, Renard taught me how a real software project evolves over time, from initial planning and development to maintenance, restructuring, and continuous improvement.
